# PRO.md — Project Requirements & Overview

## 1. Summary
**Project name:** <Your Portfolio Name>
**Owner:** <Your Name>
**One-liner:** A personal portfolio that showcases projects, skills and experience, with an AI agent that can answer visitor questions about my work.

## 2. Goals
- Present my best projects clearly in under 60 seconds of browsing.
- Make it easy for recruiters/clients to contact me.
- Demonstrate engineering skill through the portfolio itself (architecture, agents, testing).

## 3. Target Audience
| Audience | What they want |
|---|---|
| Recruiters | Skills, experience, résumé download |
| Clients | Case studies, results, contact |
| Peers | Code quality, blog, open source |

## 4. Scope
**In scope:** Home, Projects, Project detail, About, Blog, Contact, AI assistant, Admin dashboard.
**Out of scope (v1):** E-commerce, multi-user accounts, payments.

## 5. Functional Requirements
- [ ] FR-1: Visitors can browse and filter projects by tag/tech.
- [ ] FR-2: Visitors can read project case studies.
- [ ] FR-3: Visitors can send a contact message.
- [ ] FR-4: Visitors can chat with the AI assistant about my work.
- [ ] FR-5: I can manage content from a protected admin area.

## 6. Non-Functional Requirements
- Performance: Lighthouse ≥ 90 on all categories.
- Accessibility: WCAG 2.1 AA.
- SEO: Server-rendered pages, sitemap, Open Graph tags.
- Security: See `authentication-and-security.md`.
- Availability: ≥ 99% uptime on free/low-cost hosting.
